# VotoTransparente 🇵🇹

**As votações da Assembleia da República, explicadas de forma clara.**

VotoTransparente is a fast, static website that lists every initiative voted in plenary in Portugal's
Parliament since 2019 (legislatures XIV–XVII). For each one it shows what was proposed, who proposed it, how each
party voted, and (once generated) a plain-language AI summary, a critical analysis, and the expected budget impact.

Live at **https://vototransparente.pt**.

## How it works

```
Parliament open data ──► pipeline/normalize ──► data/processed/initiatives.json ─┐
 (IniciativasXIV…XVII_json)                                                      ├─► pipeline/export_site ─► site/ (Astro) ─► GitHub Pages
Initiative PDFs ──► pipeline/summarize (Gemini) ──► data/summaries/<id>.json ─────┘                           + Pagefind index
```

- **Votes come from structured official data, not from parsing PDFs.** The Parliament publishes
  [open-data dumps](https://www.parlamento.pt/Cidadania/Paginas/DAIniciativas.aspx) with every initiative, its
  procedural events, and every vote with per-party positions (and MPs who broke with their group). This replaces
  the old session-PDF parsing entirely.
- **Summaries are generated by Gemini reading the original document directly** (PDF passed to the model; `.docx`
  converted to text as a fallback). Results are cached one file per initiative in `data/summaries/` and committed, so
  each initiative is only ever summarized once. Initiatives without a summary still get a full page with their votes.
- **Every MP's voting record.** The official vote record gives each group's position and names the MPs who broke
  with it; combined with the official roster (who held each seat, for which party, on each date — `fetch_deputies`)
  and the official plenary attendance records (`fetch_attendance`), `pipeline/mp_votes.py` attributes every vote to
  each of the 230 MPs. Vote pages show how each MP voted (with absence reasons); MP pages show their full record.
- **Every fact links to its official source**: the initiative page, the full text, the exact page of the Diário da
  Assembleia da República where each vote is recorded, the attendance record of each meeting, and each MP's official
  biography. `pipeline/provenance.py` records the retrieval date and SHA-256 of every source file (shown on /sobre/).
- **The site is fully static.** One pre-rendered page per initiative (~6 KB gzipped). Search and filtering use
  [Pagefind](https://pagefind.app), which splits the index into small chunks and downloads only what a query needs —
  the browser never loads the whole dataset.

## Running locally

Requirements: Python 3.12+ with [uv](https://docs.astral.sh/uv/), Node 22+.

```bash
make setup
```

```bash
make data      # download open data + normalize votes (~320 MB of JSON, cached in data/raw/)
```

```bash
make site      # export + build the static site into site/dist
```

```bash
npm --prefix site run preview   # http://localhost:4321/
```

### AI summaries

Put a Gemini key in `.env` (`GEMINI_API_KEY=...`; billing must be enabled for the volume involved — ~5.3k documents).
Optionally set `GEMINI_MODEL` (default `gemini-4-hydrogen`) and `GEMINI_CONCURRENCY` (default 32).

```bash
make texts       # download the full text of every voted initiative into data/raw/texts/
```

```bash
make summaries   # summarize everything that has no summary yet (parallel, resumable)
```

Useful flags: `python -m pipeline.summarize --limit 50`, `--ids 315044 315054`, `--force` (regenerate),
`--upgrade` (regenerate summaries that were produced by a different model than the current one).

### Validation

`validation/` compares our vote data against the previous version's database (`validation/reference/old_parliament_data.csv`) and against
the [Mais Liberdade dashboard](https://maisliberdade.pt/escrutinio/atividade-parlamentar/). See
[`validation/REPORT.md`](validation/REPORT.md).

```bash
make validate
```

## Deployment

`.github/workflows/deploy.yml` runs on every push to `main`, daily, and on demand. It downloads the latest open data,
summarizes new initiatives if the `GEMINI_API_KEY` repository secret is set (committing the new summaries back), builds
the site, and deploys it to GitHub Pages.

One-time setup: **Settings → Pages → Build and deployment → Source: GitHub Actions**, and add the
`GEMINI_API_KEY` secret under **Settings → Secrets and variables → Actions**.
The site is served from the custom domain in `site/public/CNAME`. To serve it from
`https://<user>.github.io/vototransparente/` instead, build with `SITE_URL=https://<user>.github.io SITE_BASE=/vototransparente`
and delete `site/public/CNAME`.

## Project layout

| Path | What |
|---|---|
| `pipeline/` | Python data pipeline (fetch, normalize, texts, summarize, export) |
| `site/` | Astro static site (`src/pages/parlamento/…`) |
| `validation/` | Cross-checks against independent sources |
| `data/summaries/` | Committed AI summaries (one JSON per initiative) |

## Disclaimer

Vote data is official. Summaries are AI-generated and may contain mistakes — every page links to the official
document, which always prevails. Report problems in [GitHub Issues](https://github.com/luistodobom/vototransparente/issues).
